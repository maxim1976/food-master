# Food Master - Static Restaurant Template

Static HTML template for food and restaurant websites.

## Features

- Responsive Bootstrap design
- Modern animations with WOW.js
- Font Awesome icons
- jQuery plugins
- Multiple sections: Menu, Features, Gallery, Contact

## Structure

```
food-master/
├── assets/
│   ├── css/          # Stylesheets
│   ├── js/           # JavaScript files
│   ├── images/       # Image assets
│   └── fonts/        # Font files
├── index.html        # Main page
└── README.md         # This file
```

## Usage

1. Open `index.html` in a web browser
2. Customize the content in `index.html`
3. Modify styles in `assets/css/style.css`
4. Replace images in `assets/images/`

## Technologies

- HTML5
- CSS3
- Bootstrap 3
- jQuery
- Font Awesome
- Animate.css
- WOW.js
